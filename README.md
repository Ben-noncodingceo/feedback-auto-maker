# 学生学习规划与评价生成器

一款纯前端、无后端依赖的轻量工具，通过网页形式运行，帮助用户（如家长、老师、学生本人）快速生成个性化学习规划和综合评价。

## 产品特点

✅ **零门槛使用** - 无需编程基础，纯网页操作
✅ **跨平台兼容** - 支持 Windows/macOS，兼容主流浏览器
✅ **无后端依赖** - 所有数据处理在前端完成，无需服务器
✅ **保护隐私** - 所有输入数据仅在本地浏览器处理，不上传任何服务器
✅ **免费开源** - 基于 HTML/CSS/JavaScript 开发，完全开源

## 功能介绍

### 1. 输入模块
- **学生姓名**：支持1-20个字符（中文/英文）
- **学习科目**：预设常见科目（语文、数学、英语等）+ 自定义科目
- **学习阶段**：小学低年级、小学高年级、初中、高中
- **综合信息**：详细描述学生学习现状（10-500字）

### 2. 学习规划生成
- **学习目标**
  - 短期目标（1-2周）：针对薄弱点的具体提升目标
  - 长期目标（1-2个月）：阶段性能力提升目标

- **学习任务安排**
  - 按周划分任务（默认生成4周计划）
  - 每日学习内容明确（包含任务类型和预计耗时）
  - 支持折叠/展开查看

- **课时预估汇总**
  - 每周总学习时长预估
  - 四周总计学习时长
  - 各任务类型占比分析

### 3. 综合评价生成
- **优势分析**：提炼学生现有优点
- **不足分析**：明确当前薄弱环节
- **改进建议**：具体可操作的提升方法（最多5条）
- **鼓励寄语**：增强学生学习动力

### 4. 导出功能
- 📋 **复制内容**：一键复制所有内容到剪贴板
- 💾 **保存为TXT**：下载完整的学习规划文档
- 🖨️ **打印**：直接打印规划内容（已优化打印样式）

## 使用说明

### 基本流程

1. **填写学生信息**
   - 输入学生姓名
   - 选择学习科目和阶段
   - 详细描述学习现状（至少10字）

2. **生成规划**
   - 点击"生成规划"按钮
   - 等待1秒（模拟生成过程）
   - 自动跳转到结果页面

3. **查看与导出**
   - 查看学习规划和综合评价
   - 可折叠/展开每周任务
   - 选择导出方式（复制/保存/打印）

4. **编辑修改**
   - 点击"返回编辑"按钮
   - 修改输入信息
   - 重新生成规划

### 输入建议

为了生成更准确的学习规划，建议在"综合信息"中详细描述：

- ✅ 学生的优势科目或能力（如"数学计算能力强"）
- ✅ 存在的具体问题（如"英语词汇量不足"、"数学应用题丢分多"）
- ✅ 学习态度和习惯（如"学习认真但粗心"）
- ✅ 具体的困难点（如"物理概念理解困难"）

**示例**：
```
数学基础较好，计算能力强，但应用题解题思路不够清晰，经常丢分。
学习态度认真，但做题时容易粗心。希望提高应用题的解题能力和做题准确率。
```

## 常见问题

### Q: 生成的规划可以修改吗？
A: 当前版本生成的规划是基于输入自动生成的。如需修改，可以：
1. 点击"返回编辑"重新填写信息生成
2. 导出为TXT后手动编辑

### Q: 支持保存多个学生的规划吗？
A: 当前版本每次只能生成一个学生的规划。建议为每个学生单独生成并保存TXT文件。

### Q: 可以自定义学习任务吗？
A: 当前版本的任务是基于科目和阶段自动生成的。未来版本可能会添加自定义任务功能。

### Q: 数据会被保存或上传吗？
A: 不会。所有数据仅在浏览器本地处理，关闭页面后数据不会保留，也不会上传到任何服务器。

### Q: 为什么有些科目没有专门的模板？
A: 我们为常见科目（语文、数学、英语、物理、化学）提供了专门的模板。其他科目会使用通用模板。您可以在GitHub上提交Issue建议添加更多科目模板。
