# 学生学习规划与评价生成器 (增强版)

一款纯前端、无后端依赖的轻量工具，支持上传课程大纲和禁止词库，通过网页形式运行，帮助用户（如家长、老师、学生本人）快速生成个性化学习规划和综合评价。

## 产品特点

✅ **零门槛使用** - 无需编程基础，纯网页操作
✅ **跨平台兼容** - 支持 Windows/macOS，兼容主流浏览器
✅ **无后端依赖** - 所有数据处理在前端完成，无需服务器
✅ **保护隐私** - 所有输入数据仅在本地浏览器处理，不上传任何服务器
✅ **课程大纲支持** - 上传课程大纲，生成贴合教学进度的学习规划
✅ **禁止词过滤** - 上传禁止词库，自动过滤敏感词汇
✅ **多格式导出** - 支持TXT和DOCX格式导出
✅ **免费开源** - 基于 HTML/CSS/JavaScript 开发，完全开源

## 功能介绍

### 1. 文件上传模块（可选）

#### 课程大纲
- **文件格式**：支持 `.txt` 和 `.docx`
- **识别规则**：自动识别包含"第...章"、"第...节"、"Chapter"、"Unit"等的章节标题
- **应用方式**：上传后，生成的学习任务将按章节顺序分配到4周学习计划中

#### 禁止词库
- **文件格式**：仅支持 `.txt`
- **格式要求**：每行一个禁止词
- **应用方式**：生成的所有文本内容会自动过滤这些词汇（替换为*号）

### 2. 用户输入模块
- **学生姓名**：支持1-20个字符（中文/英文）
- **学习科目**：预设常见科目（语文、数学、英语等）+ 自定义科目
- **学习阶段**：小学低年级、小学高年级、初中、高中
- **综合信息**：详细描述学生学习现状（10-500字）

### 3. 学习规划生成
- **学习目标**
  - 短期目标（1-2周）：针对薄弱点的具体提升目标
  - 长期目标（1-2个月）：阶段性能力提升目标

- **学习任务安排**
  - 优先使用课程大纲内容（如已上传）
  - 按周划分任务（默认生成4周计划）
  - 每日学习内容明确（包含任务类型和预计耗时）
  - 支持折叠/展开查看

- **课时预估汇总**
  - 每周总学习时长预估
  - 四周总计学习时长
  - 各任务类型占比分析

### 4. 综合评价生成
- **优势分析**：提炼学生现有优点
- **不足分析**：明确当前薄弱环节
- **改进建议**：具体可操作的提升方法（最多5条）
- **鼓励寄语**：增强学生学习动力
- **禁止词过滤**：所有评价内容自动过滤禁止词（如已上传）

### 5. 导出功能
- 📋 **复制内容**：一键复制所有内容到剪贴板
- 💾 **保存为TXT**：下载纯文本格式的学习规划文档
- 📝 **保存为DOCX**：下载专业排版的Word文档
- 🖨️ **打印**：直接打印规划内容（已优化打印样式）

## 使用说明

### 完整流程

1. **上传文件（可选）**
   - 上传课程大纲文件（.txt 或 .docx）
   - 上传禁止词库文件（.txt，每行一个词）

2. **填写学生信息**

3. **生成规划**
   - 点击"生成规划"按钮

4. **查看与导出**
   - 查看学习规划和综合评价

   - 如果上传了禁止词库，会看到过滤提示
   - 可折叠/展开每周任务
   - 选择导出方式（复制/保存TXT/保存DOCX/打印）

5. **编辑修改**
   - 点击"返回编辑"按钮
   - 修改输入信息或更换文件
   - 重新生成规划

## 常见问题

### Q: 支持哪些文件格式？
A:
- 课程大纲：支持 `.txt` 和 `.docx` 格式
- 禁止词库：仅支持 `.txt` 格式
- 导出文件：支持 `.txt` 和 `.docx` 格式

### Q: 课程大纲如何被使用？
A: 上传课程大纲后，系统会自动解析其中的章节信息，并将这些章节分配到4周的学习计划中。例如，如果大纲有12个章节，每周会安排学习3个章节。

### Q: 禁止词库如何工作？
A: 系统会读取禁止词库中的所有词汇，在生成学习规划和评价时，自动将这些词替换为相同长度的*号。

### Q: 上传的文件会被保存吗？
A: 不会。所有文件仅在当前浏览器会话中处理，刷新页面或关闭浏览器后，文件内容会自动清除。

### Q: 为什么需要禁止词库？
A: 禁止词库可以确保生成的内容符合特定场景的要求，避免出现不当或敏感词汇，特别适合教育机构使用。

### Q: DOCX导出的文档是什么样的？
A: 导出的DOCX文档包含完整的学习规划和评价内容，采用专业的排版格式，可以直接使用Microsoft Word或WPS打开编辑。

### Q: 可以同时上传多个课程大纲吗？
A: 当前版本每次只能上传一个课程大纲文件。如需更换，请先移除现有文件，再上传新文件。

### Q: 生成的规划可以修改吗？
A: 当前版本生成的规划是基于输入自动生成的。如需修改，可以：
1. 点击"返回编辑"重新填写信息生成
2. 导出为DOCX后在Word中手动编辑

## 技术实现细节

### 文件读取
- 使用 `FileReader API` 读取文本文件
- 使用 `mammoth.js` 解析DOCX文件
- 使用 `ArrayBuffer` 处理二进制数据

### 课程大纲解析
```javascript
// 支持的章节格式
const chapterPatterns = [
    /第[一二三四五六七八九十\d]+[章节课单元]/,
    /Chapter\s*\d+/i,
    /Unit\s*\d+/i,
    /^\d+[\.、]\s*.+/,
];
```

### 禁止词过滤
```javascript
// 使用Set存储禁止词，O(1)查找
const bannedWords = new Set(['词1', '词2']);

// 全局替换
bannedWords.forEach(word => {
    const regex = new RegExp(word, 'g');
    text = text.replace(regex, '*'.repeat(word.length));
});
```

### DOCX生成
```javascript
// 使用docx库创建文档
const doc = new docx.Document({
    sections: [{
        children: [
            new docx.Paragraph({
                text: "标题",
                heading: docx.HeadingLevel.HEADING_1
            })
        ]
    }]
});

// 导出为Blob并下载
const blob = await docx.Packer.toBlob(doc);
saveAs(blob, filename);
```
